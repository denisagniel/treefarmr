# Paper Story — `continuum-threshold-optimal-trees`

**Instance path:** `inst/paper/story.md`
**Governed by:** `.claude/rules/paper-protocol.md`
**Status:** draft as of 2026-09-18 — stalled. The paper's load-bearing global topology margin was found false in the form the program originally relied on; it survives in the manuscript only under a global two-sided density bound strong enough to exclude discrete covariates and near-degenerate covariate dependence outright. Separately, the manuscript's own Stage-A rate conditions and its own Step-1 exclusion inequality were shown to be mutually unsatisfiable at any sample size the software realistically operates at, so the theory is asymptotically non-vacuous but empirically unreachable. The abstract, introduction, implementation, simulations, and discussion sections are still bracketed outlines; no simulation has ever been run against the current architecture. The downstream consumer that motivated the paper has since pivoted to a weaker target (L2-closeness of the fitted regression function) that does not need this paper's guarantee at all.

## Framing

Every globally-optimal decision-tree solver in current use — GOSDT-style branch-and-bound, its regression descendants, and this project's own solver — searches a *finite, pre-specified* grid of candidate cutpoints, because branch-and-bound needs a finite candidate set to certify optimality against. That is not a tuning detail; it is a structural commitment. If the data-generating regression function really is piecewise constant on an axis-aligned tree partition, its true thresholds are real numbers, and a real number generically does not land on a pre-declared grid point. So a solver that is *exactly* optimal over its grid is, with probability one, solving a problem whose optimum is not the truth. The best any grid-restricted fit can do is localise each true boundary to within half the grid mesh. That error does not shrink with sample size; it shrinks only if the analyst refines the grid, which is exactly what makes the combinatorial search explode.

The paper's proposal was to split the problem in two so that neither half pays the other's cost. Stage A runs an ordinary grid-restricted optimal-tree fit at a *coarse* resolution, at the analyst's true leaf and depth budget, with a penalty deliberately large relative to the grid mesh — and asks it for much less than a partition: only the *topology*, meaning which coordinate is split at which node, with the thresholds thrown away. Stage B then takes each recovered node in root-first order and re-optimises its single threshold by an exact one-dimensional scan over *observed covariate values* inside a shrinking window around the Stage-A split, never re-entering the combinatorial solver. The target result is a rate separation: a topology recovered with probability tending to one as the grid refines, and then every threshold in the tree simultaneously superconsistent at order one-over-n — the same rate a single change point with known location structure attains in the classical least-squares change-point literature — despite the topology itself having been estimated rather than given. The motivating consumer was a companion causal-inference paper that needed exact partition recovery, with a rate, as an off-the-shelf nuisance-estimation input; the existing optimal-tree theory it could have cited bounds excess *prediction risk* over a nonparametric class and is silent about whether the fitted partition matches any true partition.

## Contribution

As it currently stands the paper's honest contribution is negative and diagnostic rather than positive: it identifies precisely where exact topology recovery for optimal trees breaks — a global topology margin that is false without a global density floor, and a penalty regime whose direction is reversed relative to grid-exact analysis and which is therefore incompatible, at realistic sample sizes, with the grid-resolution ceiling the same theorem needs — and it documents, in the counterexamples and proof audits it carries, that this is a genuinely open problem in the field rather than a local proof-writing failure. The two-stage algorithm exists and is implemented; the guarantee attached to it holds only inside an assumption set that is not checkable at the package level even in principle.

## Scope boundary

The paper does not resolve whether the global topology margin can be recovered under a weaker condition than a two-sided density bound on the whole covariate space; that condition, added to plug a counterexample, silently removes discrete covariates from scope entirely, including covariates the true tree never splits on. It does not resolve uniqueness of the true tree in general — partition-level uniqueness is derived only after adding compactness, convexity, and full-dimensionality of the support, and is otherwise carried as a standing hypothesis; ordered-tree uniqueness is shown *not* to follow, so recovery is of an equivalence class of partitions, never of a rooted split order. The margin constant is non-explicit, obtained from an attained minimum over a finite set of template pairs, so no numerical value is available for it and no feasibility check can be computed from the theory itself. Nothing in the paper is proved for growing leaf budget, growing depth, or growing covariate dimension: the concentration argument enters dimension only through a constant, and only conditional on dimension being fixed. Classification loss is not covered by the two-stage algorithm. Most consequentially, the paper contains no empirical content at all — the simulation section is an outline that has been redirected twice, its own feasibility gate arithmetic has never been checked against a run, and the shipped software's default grid ladder sits in the region that arithmetic identifies as infeasible.

## Major claims

- **S1:** The global topology margin — the claim that any within-budget tree failing to match the true tree structurally pays a fixed, non-vanishing excess risk, whatever coordinates it splits on — is false in the marginal-density form the program originally relied on. Near-deterministic dependence between covariates lets a tree split on the wrong coordinate and still achieve near-zero excess risk, and this was settled by explicit counterexample, not by failure to find a proof.

- **S2:** The margin can be rescued only by assuming a density floor and ceiling on the *entire* covariate space, which is close to assuming away the failure rather than analysing it: a vanishing density on any region reinstates the wrong-coordinate counterexample, and the assumption's cost is that every covariate must be continuous, not merely every covariate the true tree splits on.

- **S3:** The penalty regime the topology-recovery argument requires runs in the opposite direction from what a grid-exact analysis would suggest — the penalty must dominate the grid approximation error rather than be dominated by it — and this reversal is what makes the paper's own conditions internally incompatible at practical sample sizes. The Step-1 over-splitting exclusion needs the product of grid resolution and penalty to exceed a constant fixed by the true jump sizes and leaf budget, while the grid-resolution ceiling caps resolution against sample size and the penalty is separately required to be small. No admissible pair satisfies both until roughly hundreds of thousands to millions of observations.

- **S4:** The predicted failure mode below that boundary is over-splitting, and in the shipped implementation it is masked rather than absent: the leaf-budget selector raises the penalty until the leaf count matches the declared budget, so a user sees a budget-respecting, certified tree and never observes the symptom the theory predicts. Three of five rate conditions are violated by the package's own default call.

- **S5:** The search-window guarantee that Stage B depends on is not delivered by the implementation as written, for a reason independent of the theory: the grid is built in quantile (probability) space while the window radius is sized in raw covariate units, so on any coordinate with a low-density region the effective window collapses and the off-grid scan silently finds no candidates and keeps the grid cut. Stage B then does nothing, recorded only in an internal diagnostic column.

- **S6:** The superconsistency claim itself has never been checked empirically at any setting, under the current architecture or any other. The only recorded numbers from the adjacent program are a four-replication smoke test at the smallest leaf budgets; the designed study crashed before producing a single replication at the target range, on a tied-optimal-tree enumeration blow-up in the solver's single-tree extractor that was subsequently fixed but whose timing consequences were never measured.

- **S7:** The program the paper was written to serve has moved on. Exact topology recovery was judged infeasible beyond very small trees at practical sample sizes, and the downstream causal-inference work now targets L2-closeness of the fitted nuisance functions instead — a target that escapes the margin problem entirely and does not consume this paper's guarantee. The paper's remaining value, absent a solution to S1 and S3, is as a precise account of why the direct route fails.
